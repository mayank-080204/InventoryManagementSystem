# Inventory Management System

A web-based Inventory Management System developed using ASP.NET Core MVC and SQL Server to manage products, categories, suppliers, and stock transactions.

## Features

- Product management (Create, Read, Update, Delete)
- Category management
- Supplier management
- Stock transaction management
- SQL Server database integration
- Entity Framework Core for database operations
- Responsive user interface using Bootstrap

## Technologies Used

- C#
- ASP.NET Core MVC
- Entity Framework Core
- Microsoft SQL Server
- HTML, CSS, JavaScript
- Bootstrap
- Git and GitHub

## Project Structure

- `Controllers` — Handles application requests and business logic.
- `Models` — Defines application data models.
- `Views` — Contains Razor views for the user interface.
- `Data` — Contains the database context.
- `Migrations` — Contains Entity Framework Core database migrations.

## Getting Started

1. Clone this repository.
2. Open `InventoryManagementSystem.sln` in Visual Studio.
3. Update the SQL Server connection string in your local configuration.
4. Apply the Entity Framework Core migrations.
5. Run the application.
